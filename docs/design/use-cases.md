# MVPのユースケース整理

**ユースケース**

利用者が目的を達成するために行う一連の行動・ユーザー視点の目的

ユースケースはなぜその機能が必要かを書く。
設計はどう実現するかを書く。

1. ユーザー登録
- ユーザーが
- アプリの利用を開始するために
- ユーザー情報を登録する

2. ログイン
- ユーザーが
- アプリを利用するために
- ログインする

3. 車両管理
- ユーザーが
- 過去に乗った車を記録し振り返るために
- 車両情報を登録・編集・閲覧する
補足：
登録した車両はドライブ記録作成時に再利用できる

4. ドライブ記録管理
- ユーザーが
- ドライブ体験を記録し振り返るために
- ドライブ記録を登録・編集・閲覧する

5. 写真管理
- ユーザーが
- ドライブ体験を視覚的に振り返るために
- 写真を登録・閲覧する


メモ
cars
→ ユーザーが乗った車を管理する

drive_records
→ 1回のドライブ体験を記録する

photos
→ ドライブ体験に紐づく写真を管理する

## 機能要件

### 【認証】
- 特別な要件はなし
- Laravelの標準機能を使う

### 車両管理
目的
- 過去に乗った車を記録し振り返る

要件
- 車両を登録できる
- 車両を編集できる
- 車両を閲覧できる
- ドライブ記録作成時に選択できる
- 車両ごとの乗車履歴を確認できる
- 車両写真を登録できる

### ドライブ記録管理
目的
- ドライブ体験を記録し振り返る

要件
-ドライブ記録を登録できる
- ドライブ記録を編集できる
- ドライブ記録を閲覧できる
- 登録済み車両を選択できる
- ドライブ体験の感想や気づきを記録できる
- 写真を登録できる

### 写真管理
目的
- ドライブ体験を視覚的に振り返る

要件
- 写真を登録できる
- 写真を編集できる
- 写真を閲覧できる
- 車両・ドライブ記録に紐づく写真を表示できる


## 設計検討メモ

### 車両管理
- メーカーのサイトのリンクを登録できる
    - Phase2以降に検討

- ドライブ記録作成時に選択できる
    - 理由：ドライブ記録作成時に同じ車両情報を繰り返し入力しなくてよい

- 車両ごとの乗車履歴を確認できる

- 履歴情報
- 車両単位で振り返り可能
    - 回数
    - 距離

- 車両写真を登録できる
    - 作成時に車両の写真を紐付けて登録できる
    - 車両写真は写真管理のアルバムで閲覧できる

- 車両詳細画面（案）
    - レヴォーグ GT-H EX
    - カーシェア
    - ステーション 新宿駅前
    - 乗車回数：12回
    - 総走行距離：1,850km
    - 関連ドライブ記録
    - 車両写真
    - URL
    - メモ

- マイカー、レンタカー/カーシェアを選択できる

- 関連ドライブ記録
    - 箱根ドライブ
    - 富士山一周
    - 伊豆旅行

### ドライブ記録管理

- 走行モードを記録するか検討
    - Sモード、Iモードなど個々の運転記録ごとに変わる情報

- ドライブ記録詳細画面（案）
    - 車両：（選択）
    - レヴォーグ GT-H EX
    - ルート情報
    - 出発地
    - 目的地
    - 立ち寄りポイント
        - お気に入りスポットやルート登録機能との兼ね合いを後で整理

- 道路の種類
    * 一般道（市街地）
    * 一般道（生活道路）
    * 高速道路
    * 首都高
    * ワインディング
    * 酷道
    - 上記から選択
    - その他選択で任意の値を保存できる

- 距離
    - 紐付けた車両に加算される
    - 同じ車種で個体が違う場合を後で検討

- 今回のテーマ
    - 楽しかったこと・発見
    - うまくできたこと
    - 難しかったこと・気づいた課題
    - 感覚メモ・車との対話

- 次回に向けて
    - 試してみたいこと
    - 行ってみたい場所

- 写真・動画

### 写真管理
- 車両管理とドライブ記録で登録した以外の場合も登録できる？
- 絞り込みで車両、ドライブ記録で分けて閲覧できる


# アプリ概要

## 背景

Obsidianで運転記録を管理している。

今のままでも管理はできるが以下のような課題がある。

* ノート作成が大変
* フォーマット適用が手間
* 一覧や検索が弱い
* 写真管理が分離
* 集計しづらい

### 詳細エピソード

* 毎回ノート作成→フォーマット適用の手間がかかる
* 毎回フォーマットを考えるのが大変
* ノートは手作り感があって独自の良さはあるが、一覧・検索・集計・情報の再利用はアプリほど柔軟にはできない
* 登録した写真を手動でノート貼り付けているが、ノートの場合、貼り付けた場所でしか見ることができない
* これまでどんな写真を撮ったのか全体は把握できない
* 個別の運転記録の中だけでなくアルバムのような場所で一覧確認したい


## 解決（実現）したいこと

ノートに登録している情報をアプリ独自で実現できる機能を使って、
1度のドライブ体験の価値を最大化したい

### アプリだからできること（技術を使って何を価値化したいのか）
* 検索
* 集計
* 一覧
* コレクション性
* 再利用

### プロダクトの思想・コンセプト

上記のアプリの長所を活かして、体験という情報がもつ価値を最大化したい
Obsidian運用の限界を、アプリならではの価値で拡張したい

**体験の価値最大化**
* 記録
* 振り返り
* 体験蓄積
* 再発見
* 思い出
* 学び

例：
車両登録・お気に入りルート・スポットについて登録して繰り返し使いたい
一覧や検索もしたい

**一覧機能があると・・・眺めるだけで自分の傾向や振り返りができる**
- 自分はこんな場所に行くのが好き
- 数年前はこんなところに行っていた
- 自分はこんなタイプの車が好き
など

- コレクション性もある
- 記録が増えていくことが視覚的にわかる
- 記録数に応じてスタンプなどあると楽しめる

**検索機能・・・情報が増えるほど価値が出る**
- 検索（の条件）自体がその情報はどのような価値があるのかを示す
- 「人は何を振り返りたいのか」を示す
- あの車に乗ったのはいつだったか
- あの場所には何回行ったのか
など

**集計・・・**
- 距離・場所など今月の履歴を出したい
- 履歴一覧だけでなく今月何キロ走った、何県に何回行ったなどを集計
- 他にも面白い分析ができそう
- ノートに記録しているだけでは気づかないことがわかって面白い

**UI・・・**
- 車のアプリはクール・メカニックなデザインものが多い印象
- また、自動車メーカーなどバイクなど特定のグループを想定したものが多い印象
- 初心者、特別車や運転に詳しくない人も気軽にできるような親しみやすい、癒し系のデザインにしたい

**本質（思想）・・・車・運転好き向けというより、「体験記録アプリ」を通して車・運転を好き・楽しいと思えるようなものにしたい**

（従来型）
車・運転好き → 特化アプリ

（このアプリ）
ある程度誰でも利用できる体験アプリ → 車・ドライブをゲームのように記録することで楽しくなる

**将来的には・・・**
* 地図
* 交流
* ローカル知見共有
といった機能を拡張したい

- 地図を表示して運転で移動した経路を画面に表示したい
- 他ユーザーとの体験シェア・交流機能
- 運転技術の継承というテーマが気になっている

教習所指導員などプロドライバーでなくても
ベテランドライバー・その土地を長年運転してきたローカルドライバーの知見は価値があると思う

それが個人の話になっているのが勿体無いと感じるため、
なんらかの形で共有できるサービスがあればと思っている
